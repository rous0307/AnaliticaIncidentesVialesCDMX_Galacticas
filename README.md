## 📌 Breve Descripción
Proyecto de BI para analizar patrones de incidentes viales en la CDMX (C4/C5, 2017-2019). Identifica alcaldías, días y franjas horarias de mayor concentración de accidentes para apoyar a la SSC y SEMOVI en la reasignación estratégica y preventiva de patrullas y ambulancias.
