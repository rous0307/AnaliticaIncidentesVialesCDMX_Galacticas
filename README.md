# AnaliticaIncidentesVialesCDMX_Galacticas
Proyecto de BI para analizar patrones de incidentes viales en la CDMX (C4/C5, 2017-2019). Identifica alcaldías, días y franjas horarias de mayor concentración de accidentes para apoyar a la SSC y SEMOVI en la  estratégica y prevención de patrullas y ambulancias.
